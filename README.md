# 量潮实验室

产品和技术实验室，按 quanttide/quanttide 的 default/domains 建模。

## 结构

```
quanttide-laboratory/
├── default/company/     # 公司模板（量潮科技实验室）
└── examples/            # 各领域实验
    ├── execute/         # 执行
    ├── game/            # 游戏
    ├── human/           # 人力资源
    ├── org/             # 组织
    └── innov/           # 创新
```
